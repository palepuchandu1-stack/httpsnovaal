# NOVA AI — Palepu Chandu

మీ ZIPలోని డిజైన్, పేరు అలాగే ఉంచి వెబ్‌సైట్‌ను Netlifyకు అనుగుణంగా మార్చాం.

చాట్, వెబ్ సెర్చ్, ఇమేజ్/PDF విశ్లేషణ, ఇమేజ్ జనరేషన్ సర్వర్ ఫంక్షన్ల ద్వారా పనిచేస్తాయి. AI వినియోగానికి Netlify క్రెడిట్లు అవసరం. బ్రౌజర్‌కు API కీలు పంపబడవు.

మొబైల్‌లో కూడా టూల్స్ అందుబాటులో ఉన్నాయి. ఒక్కసారి ఒక ఫైల్, గరిష్ఠంగా 3 MB అప్‌లోడ్ చేయవచ్చు. వాయిస్ ఇన్‌పుట్‌కు మైక్రోఫోన్ అనుమతి, మద్దతు ఉన్న బ్రౌజర్ అవసరం. చాట్ హిస్టరీ సేవ్ కాదు; పేజీ రిఫ్రెష్ చేస్తే తొలగిపోతుంది.

లోకల్ సెటప్ వివరాలు README.mdలో ఉన్నాయి.
